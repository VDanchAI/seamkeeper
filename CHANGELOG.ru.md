## v1.0.0 — 17.09.2026

Первый релиз с тегом. Сам протокол работает в проде с августа 2026; в этот релиз вошла
работа по совместимости, описанная ниже.

### ⚠️ Прочти это, если бот запустился и молчит

**В Claude Code 2.1.273 перевернули диалог доверия к папке.** Если у тебя эта версия (или
новее), а скрипты запуска написаны под более старые, картина будет такая:

- в логе написано `started`
- `tmux has-session` говорит, что сессия есть
- бот не отвечает вообще ни на что

Причина: Claude спрашивает *«Do you trust the files in this folder?»*, и с 2.1.273 по
умолчанию подсвечен **отказ**. Старые скрипты жали слепой `Enter`, который раньше означал
согласие — а теперь выбирает **выход**. Claude закрывается через секунду после запуска.
Отказ тихий и выглядит как успех, поэтому и вынесено в начало.

### Какое поведение у тебя

От тебя ничего не требуется: `core/start-claude-telegram.sh` читает `claude --version` и
подстраивается сам. Таблица — для понимания и для тех, кто переносит скрипты к себе:

| Твоя версия Claude Code | Что подсвечено по умолчанию | Что жмёт скрипт |
|---|---|---|
| **2.1.273 и новее** | отказ (`No, exit`) | `Down`, затем `Enter` |
| **старее 2.1.273** | согласие (`Yes, I trust`) | только `Enter` |
| версия не определилась | считаем, что новая | `Down`, затем `Enter` |

То есть на старой установке всё работает как раньше, а после обновления Claude Code
поведение переключится само. Если форкаешь эти скрипты — не зашивай «нажать N-ю клавишу»:
порядок вариантов Anthropic уже менял однажды.

### Исправлено

- **Перевёрнутый диалог доверия** в `core/start-claude-telegram.sh` и
  `core/restart-channel-fresh.sh`. Нажатие выбирается по определённой версии Claude Code,
  а не зашито жёстко.
- **Согласие не сохранялось** между запусками, из-за чего диалог вылезал на каждом рестарте.

### Добавлено

- **Слой профилактики, не зависящий от версии.** Перед запуском рабочая папка объявляется
  доверенной в `~/.claude.json` (`projects."<путь>".hasTrustDialogAccepted`) — тогда диалог
  вообще не появляется. Запись идёт через временный файл в том же каталоге и атомарную
  замену: обрыв на записи не оставит тебя с обрезанным `~/.claude.json`. Битый или
  недоступный конфиг не трогается — скрипт откатывается на слой с нажатием, вместо того чтобы
  сделать хуже. Прочие ключи и права файла сохраняются; уже выставленное доверие
  не перезаписывается.
- **Подсказка по диагностике** в `docs/SETUP.md` и `docs/SETUP.en.md`: если в логе `started`,
  а бот молчит — смотри экран сессии через
  `tmux capture-pane -t telegram -p | tail -20`, застрявший или отклонённый диалог доверия
  виден там сразу.
- **Раздел о совместимости** в оба README.

### Проверено

Поведение порядка вариантов подтверждено на Claude Code 2.1.273. Сравнение версий проверено
на 2.0.9, 2.1.0, 2.1.272, 2.1.273, 2.1.300, 2.2.0, 1.9.9 и 3.0.0. Запись в конфиг проверена
на копиях: добавляет доверие, сохраняя остальные ключи; не перезаписывает уже выставленное;
не портит битый JSON; создаёт файл, если его нет.
