Владелец попросил: неясное в задаче уточнять ПЕРЕД стартом, а не догадываться.

**Почему:** додуманный не туда скоуп жёг токены и время; владелец хочет понимать ход работы.

**Как применять:** перед нетривиальной задачей собрать развилки (разные толкования → разная
работа) и задать одним сжатым сообщением. Мелкие однозначные решения — делать самому.
